# Murugan collection

The canonical sources are `murugan_src.json` and `murugan_tamil_src.json`.

```
node tools/ganesha-build.mjs murugan
node tools/check-murugan.mjs
```

Ten entries: complete 33-verse Subrahmanya Bhujangam; eight-verse Agastya Skanda Ashtakam; five-verse deva Kartikeya stotra; one-verse Shakti Stuti; three-verse sixteen-name hymn; Kandar Anubhuthi (invocation + 51); Shanmuga Kavasam (30); Pagai Kadithal (10); Muththaiththaru (eight reading blocks); Erumayil Eri (four couplets).

Agastya Skanda Ashtakam and Shadanana Ashtakam have substantially the same text; one entry has both search names. The eight prayer verses are used, not the ninth narrative sentence in one edition. Purana speaker roles are distinguished from historical authorship. The deva stotra source has inconsistent chapter numbering in its colophon versus metadata; this is disclosed. Adi Shankara and Shankaracharya are search aliases for the same traditionally attributed author. The sixteen-name hymn is not arbitrarily attributed to Agastya.

Tamil originals are ancient or public-domain works, with new Tamil paraphrases. No modern web commentaries, translations, music or recordings are copied. These paraphrases await specialist review. Devotional illness/protection claims remain prayers and beliefs, not practical medical instructions or promised outcomes. Recitation days and counts are optional.

The separate source-book library includes the user's Bogar volumes and other Siddhar books intact. This collection does not claim to contain every Murugan/Siddhar composition or all 1,300+ Tiruppugazh songs.
